# @amlplugins/google-fonts

Native `@googleapis/webfonts` SDK re-exported under the `@amlplugins` namespace.

> Google Fonts Developer API.

## Install

```bash
npm install @amlplugins/google-fonts
```

## Use

```ts
import { /* named exports from @googleapis/webfonts */ } from "@amlplugins/google-fonts";
// or
import sdk from "@amlplugins/google-fonts";
```

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
